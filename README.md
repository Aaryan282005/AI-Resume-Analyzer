# AI Resume Analyzer & Intelligent Job Matcher

An AI-powered application that analyzes resumes and compares them
with job descriptions using NLP, Machine Learning, Embeddings,
and Generative AI.

## Project Objective

The system will:

- Extract information from resumes
- Identify candidate skills
- Analyze job descriptions
- Compare resumes with job requirements
- Identify skill gaps
- Generate AI recommendations
- Generate interview questions
- Provide a personalized learning roadmap

## Technology Stack

- Python
- PyMuPDF
- spaCy
- Pandas
- NumPy
- Scikit-learn
- Google Gemini
- LangChain
- FAISS
- Streamlit
- FastAPI
- SQL
- Docker
